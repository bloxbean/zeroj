03 · TYPED UINT

Meet a threshold

A range-constrained secret age of 21 meets a public threshold of 18. This arithmetic example does not authenticate anyone’s age.

defineCircuit({
  name: 'age_check',
  public: { threshold: uint(8) },
  secret: { age: uint(8) }
}, ({public: p, secret: s}) => {
  s.age.gte(p.threshold).assertTrue();
});

05 · EXISTING POSEIDON GADGET

A commitment relation

Call ZeroJ’s BLS12-381 T3 Poseidon implementation. Compile the 241-constraint relation, load its 1.09 MB key in bounded chunks, then generate and verify a fresh proof in the browser. The salt is public test data; this fixture is not a private application.

zk.gadgets.poseidonBls12381T3(s.value, s.salt)
  .assertEqual(p.commitment);

07 · FIXED ARRAYS + EXISTING MERKLE GADGET

Prove allowlist membership

Keep the leaf, sibling and path direction private to the prover. The public root identifies the approved two-leaf tree. This demo uses known test values; it does not establish a person’s identity or hide these published fixtures.

secret: {
  leaf: field(),
  siblings: array(field(), 1),
  pathBits: array(bool(), 1)
}
// false = current node is left; true = current node is right
zk.gadgets.merkleRootBls12381T3(
  s.leaf, s.siblings, s.pathBits
).assertEqual(p.root);

The local Cardano runner pins the root and authorized signer and accepts only its claim action. The signature authorizes the transaction, and Cardano prevents the same UTxO from being spent twice. Membership proofs remain reusable for other deposits. This is not an anonymous, nullifier-based protocol.
