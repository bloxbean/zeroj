ZEROJ · EXPERIMENTAL WEB SDK

Java cryptography.
In your browser.

These examples run locally in a worker. Each capability loads its own selected WebAssembly bundle only when you use it.

01

Hash a document

Compare the browser's SHA-256 with the same input hashed by ZeroJ's Java code compiled to Wasm. BLAKE2b runs through ZeroJ too. These are ordinary hashes, not zero-knowledge proofs.

No Wasm has been downloaded yet.
02

Commit, then reveal

Keep a value hidden with a fresh blinding. Later, disclose its opening so another party can check the commitment.

value + blinding → commitment → disclosed opening
Ready. Uses disposable test data.
03

Show one credential claim

Issue a disposable two-claim credential, then prove “over-18” while hiding the member identifier. A fresh verifier challenge binds this presentation.

issuer signs → holder selects claims → verifier checks
Ready. Uses disposable test data.
04

Prove a private computation

Generate and verify a real BLS12-381 Groth16 proof for y = x³ + x + 5. The example uses x = 3 and a development-only key.

private x → ZeroJ prover → proof + public y
Ready. Uses disposable test data.
05

Count encrypted votes

Encrypt three sample votes and add their ciphertexts. Both trustees supply shares to decrypt only the final tally. This local example holds all keys.

encrypted votes → encrypted sum → all trustees
Ready. Uses disposable test data.
06

Try 2-of-3 decryption

Run seven DKG rounds locally, then decrypt with two of three participants. This demonstrates the protocol, not a distributed trust setup. Real deployments need authenticated private channels, broadcast agreement and round closure.

3 participants → DKG → any 2 qualified shares
Ready. Uses disposable test data.
07

Deliver a confidential note

Seal a value for its owner and an auditor. Each reader opens its own delivery and checks the commitment. An altered delivery must fail. Spending and ledger state rules are separate.

opening → commitment + deliveries → owner / auditor
Ready. Uses disposable test data.
